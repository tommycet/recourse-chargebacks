What It Does

Three primitives that make agent payments safe

🔒

Onchain Escrow

Payment is locked in a smart contract before work begins. Funds can't move until the buyer confirms delivery — or the arbiter resolves a dispute.

⚖️

AI Dispute Resolution

When something goes wrong, an on-chain arbiter reviews cryptographic evidence and issues a binding refund or payout. Machine-speed, deterministic, no intermediaries.

⚡

KeeperHub Execution

Every action flows through KeeperHub's MCP server and Direct Execution API. Dual surface, auto-failover, full audit trail — from trigger to on-chain settlement.

Multi-Agent Pipeline

Four independent agents, one onchain verdict

Every dispute flows through four specialized agents that verify independently before KeeperHub executes. No single agent can force a settlement — each phase gates the next.

Phase 1

Evidence Verifier

keccak256 proofs, source/target signatures, delivery verification

fail → dispute raised

→
Phase 2

AI Arbiter

LLM + rule-based fallback, evidence review, binary verdict

verdict → refund or pay

→
Phase 3

Policy Agent

Refund/payout matching policy, gas-aware routing, retry on spike

optimized → Phase 4

→
Phase 4

KeeperHub

MCP + Direct API, onchain execution, audit trail logged
